Meridian 1.2 is the first release built for everyone: notarized by Apple, readable with VoiceOver, and tightened by a full review of 1.1.

![Today, a watchlist, a one-year chart and the filings inbox](https://raw.githubusercontent.com/ankthba/meridian/main/docs/screenshots/workspace.png)

## Install

Download **Meridian-1.2.0.dmg** below, open it, and drag Meridian onto Applications. It's signed with a Developer ID and notarized, so it opens like any other app. Requires macOS 15 or later on Apple silicon.

Coming from 1.1: replace the app; your keys, portfolio and settings stay. macOS may ask once per saved key for your login password because the app is now signed differently: click **Always Allow**.

## What's new

- **Updates:** Meridian checks GitHub for new releases (at launch and daily; Settings → General turns it off) and says so in the top bar. Meridian → Check for Updates… checks now.
- **First run:** Today starts with a **Get started** list of the free sources to connect and what each adds, instead of a page of NOT AVAILABLE lines.
- **Menus:** File → Import Portfolio…, a Terminal menu for Today, Calendar, Filings and Portfolio, and Help with the guide, Report an Issue… and crash reports.
- **VoiceOver:** panes, tables, charts and the command bar are labeled; tick flashes respect Reduce Motion.
- **Calendar** shows earnings and dividends while a slow macro calendar loads.

## Fixes

- Portfolio repeated an added transaction on later clicks, reloads and relaunches; watchlist and alert actions too. Actions now run once.
- Return in the command bar could open a look-alike ticker (`GP 5Y` charted GreenPower Motor).
- Imports with mapped columns couldn't be saved.
- Today's change left out positions sold out today.
- ASK re-sent its question on every launch.
