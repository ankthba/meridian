## Gotchas

- **Polygon.io is now Massive** (renamed 2025-10-30). Target `api.massive.com`. The Financials vX endpoint was sunset 2026-06-22; use `/stocks/financials/v1/*`.
- **IEX Cloud shut down** 2024-08-31.
- **IEX licensing changed** 2025-02-01. Tiingo without a signed agreement gets a derived price; Databento dropped live IEX TOPS.
- **Not full market** despite a "real-time" label: Alpaca Basic (IEX), Tiingo (IEX), EODHD WS (EDGX), Twelve Data (~5%), Intrinio (modelled), Databento Mini (synthetic NBBO). **Consolidated/SIP:** Massive Advanced, Alpaca Plus, IBKR, Tradier.
- An embedded key would count as redistribution. Each user must use their own key; this app is personal so that's fine.
- Finnhub requires deleting data when the subscription ends (see `ARCHITECTURE.md` §6 `purge_provider`).
